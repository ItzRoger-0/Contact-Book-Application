# Contact Book

A simple Python command-line application for managing contacts. Users can add, view, edit, delete, and list contacts using an easy menu-driven interface.

## Features

- Add new contacts
- View contact details
- Edit existing contacts
- Delete contacts
- List all contacts

## Run

```bash
python contact_book.py
```

## Built With

- Python 3
- Dictionaries
- Functions
